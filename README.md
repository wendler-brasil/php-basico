PHP Básico

Atividades práticas de Programação Web I (Técnico em Informática).

Aluno: Wendler 202

Projetos
01-hello-world: primeira página em PHP.  

02-data-hora: exibição da data e hora do servidor e saudação conforme o horário.

03-imc: calculadora de Índice de Massa Corporal (IMC), com classificação e formulário.

04-produtos: lista de produtos utilizando arrays associativos, tabela HTML e controle de estoque.

Como executar

Instalar o Laragon e iniciar os serviços Apache e MySQL (se necessário).

Colocar esta pasta em C:\laragon\www\php-basico.

Abrir o navegador.

Acessar http://localhost/wendler/php-basico/.

O que aprendi

Criar páginas web utilizando PHP e HTML.

Trabalhar com variáveis, tipos de dados, operadores e condicionais.

Utilizar funções de data e hora e formatar números.

Criar e percorrer arrays associativos utilizando foreach.

Utilizar funções, formulários e exibir informações de forma dinâmica.

Soluções alternativas que testei

Data e hora: utilizei concatenação e interpolação de variáveis para montar mensagens.

Saudação: utilizei if, elseif e else para verificar o horário.

IMC: utilizei operadores matemáticos e condicionais para classificar o resultado.

Produtos: utilizei foreach para percorrer arrays e usort() para ordenar os produtos por preço.

Formatação: utilizei number_format() para formatar valores monetários.

Segurança: utilizei htmlspecialchars() para proteger a exibição de textos na página.
